BirdMatch Lima
Prototipo interactivo para la sesión Creatividad y colaboración del curso Gestión de las relaciones en las organizaciones.

La herramienta presenta un ejemplo de "Tinder para observadores de aves en los parques de Lima". El objetivo no es construir una app real de citas, sino mostrar cómo una lógica de match puede ayudar a resolver una necesidad social o colaborativa: conectar personas con intereses, niveles de experiencia y objetivos complementarios.

Objetivo pedagógico
Este ejemplo sirve como disparador para que los estudiantes diseñen su propio "Tinder para..." aplicado a otra necesidad.

Después de explorar BirdMatch Lima, los estudiantes pueden preguntarse:

¿Qué necesidad concreta queremos resolver?
¿Quiénes serían los usuarios?
¿Qué información tendría cada perfil?
¿Qué significa hacer match en este contexto?
¿Qué acción concreta ocurre después del match?
Cómo usarlo
Abrir el archivo index.html en el navegador.
Revisar los perfiles de observadores de aves.
Usar los botones inferiores para pasar perfiles o mostrar un match.
Observar cómo el match propone una actividad concreta: lugar, hora y objetivo.
Diseñar una nueva versión de la idea para otro público o problema.
Publicar en GitHub Pages
Crear un repositorio en GitHub.
Subir el archivo index.html a la raíz del repositorio.
Subir también este README.md.
Ir a Settings > Pages.
En Build and deployment, seleccionar la rama principal.
Guardar y abrir la URL generada por GitHub Pages.
