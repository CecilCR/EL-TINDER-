Estilo de observación
💡
¿Qué es un match aquí? Dos observadores con intereses complementarios para compartir una experiencia de exploración.
🔀
Algoritmo de complementariedad: no busca personas iguales. Busca combinaciones como 🐣 principiante + 🦅 experto = aprendizaje compartido.
📍
Propuesta post-match: la plataforma genera un plan concreto: lugar, hora y objetivo específico para la salida.
🎯
Problema que resuelve: convierte una actividad individual en una experiencia social, colaborativa y situada.

Para diseñar otro Tinder

  1. 1Elige una necesidad cotidiana, social, educativa u organizacional.
  2. 2Define quiénes son los usuarios y qué información aparecería en sus perfiles.
  3. 3Explica qué significa un match y qué acción concreta ocurre después.

Usa los botones inferiores para pasar perfiles o mostrar el match. También puedes usar las flechas del teclado (←, →, ↑) o números (1, 2, 3). Este ejemplo está pensado como disparador de ideas para la sesión.
